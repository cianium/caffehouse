## معرفی پروژه

**BODRIN** یک تجربه وب واکنش‌گرا برای معرفی قهوه تخصصی است. سورس فعلی بر تجربه بصری و تعامل کاربر تمرکز دارد: مدل و افکت‌های سه‌بعدی، معرفی محصولات، انتخاب قهوه، سبد خرید، رابط تسویه نمایشی و یک فضای مدیریتی آزمایشی.

این مخزن **سورس فرانت‌اند** را نگهداری می‌کند؛ وجود صفحات سفارش و پنل مدیریت به معنی وجود سامانه عملیاتی سفارش، درگاه بانکی تأییدشده یا مدیریت امن هویت نیست.

## قابلیت‌های موجود در سورس

| بخش | قابلیت | وضعیت |
| --- | --- | --- |
| **ویترین محصولات** | معرفی و نمایش قهوه‌ها، کارت محصول و شخصی‌سازی انتخاب | رابط کاربری آزمایشی |
| **تجربه سه‌بعدی** | جلوه‌های Three.js، حرکت‌ها و انیمیشن‌های GSAP | پیاده‌سازی فرانت‌اند |
| **انتخاب قهوه** | آزمون انتخاب طعم و راهنمای دم‌آوری | تعاملی / نمایشی |

| **پرداخت** | کامپوننت شبیه‌سازی درگاه پرداخت ایرانی | **بدون پرداخت واقعیِ تأییدشده** |
| **مدیریت** | صفحات ورود و داشبورد مدیریت | **بدون احراز هویت امن سمت سرور** |
| **وفاداری** | نمایش امتیاز و پاداش در رابط | مبتنی بر داده‌ها/وضعیت مرورگر |

## پشته فناوری

- **Frontend:** React 19، TypeScript و Vite
- **Design:** Tailwind CSS، Motion و Lucide
- **3D & animation:** Three.js و GSAP
- **Development tooling:** Node.js / npm؛ فایل `bun.lock` نیز در مخزن موجود است
- **Backend / database:** در سورس بررسی‌شده، یک بک‌اند امن و عملیاتی برای کاربران، سفارش‌ها و پرداخت‌ها تأیید نشده است

## شروع توسعه محلی

ابتدا نسخه‌ای از Node.js و npm نصب کنید که با وابستگی‌های پروژه و Vite سازگار باشد.

```bash
git clone https://github.com/cianium/caffehouse.git
cd caffehouse
npm install
npm run dev
```

آدرس توسعه در تنظیمات فعلی پروژه: **http://localhost:3000**

برای بررسی TypeScript و ساخت نسخه استاتیک:

```bash
npm run lint
npm run build
npm run preview
```

> **نکته:** دستور `lint` فعلاً فقط `tsc --noEmit` را اجرا می‌کند؛ جایگزین تست امنیت، Unit Test یا E2E نیست. نتیجه اجرای این دستورات روی محیط فعلی مستقلاً در این بررسی تأیید نشده است.

فایل `.env.example` شامل نمونه متغیرهای محیطی است. **کلیدها و توکن‌های واقعی را در Git یا کد کلاینت قرار ندهید**. وجود تنظیمات نمونه Gemini به‌تنهایی نشانه پیاده‌سازی امن قابلیت AI نیست.

## هشدارهای امنیتی و عملیاتی

**احراز هویت مدیر امن نیست.** در `src/context/AdminAuthContext.tsx` رمز عبور تنها از نظر طول کنترل می‌شود، کد OTP داخل مرورگر تولید/بررسی می‌شود و وضعیت نشست در `localStorage` ذخیره می‌شود. این مکانیزم نباید محافظ داده‌ها، سفارش‌ها یا مجوزهای واقعی باشد.

**پرداخت فقط نمایشی است.** کامپوننت‌های پرداخت به معنی اتصال معتبر به PSP یا تأیید تراکنش نیستند. ورود اطلاعات بانکی واقعی، ثبت سفارش مشتری حقیقی یا تبلیغ این دمو به‌عنوان فروشگاه آماده بهره‌برداری مناسب نیست.

برای شرح دقیق ریسک‌ها و پیش‌نیازهای تبدیل پروژه به محصول، [گزارش موانع انتشار](docs/PRODUCTION_BLOCKERS.md) را بخوانید.

## انتشار و GitHub Pages

مخزن در GitHub دارای سابقه **اجرای موفق GitHub Pages** است؛ اما موفقیت انتشار فایل‌ها به معنی ساخته‌شدن صحیح اپ React/Vite یا سلامت عملکرد سایت نیست.

نسخه Vite باید ابتدا **Build** شود و خروجی مناسب `dist/` در مسیر صحیح میزبانی منتشر شود. تنظیم `base`، مسیر منابع و بازگشت مسیرهای برنامه نیز باید برای میزبانی زیرمسیر بررسی شوند. وب‌اپلیکیشن فعلی با بررسی مستقل مرورگر و آدرس نهایی تأیید نشده است؛ بنابراین فعلاً آدرس Demo را به‌عنوان سایت آماده معرفی نمی‌کنیم.

**این پروژه هنوز برای Production آماده نیست.** پیش‌نیازهای مهم:

1. احراز هویت و مجوزدهی واقعی در بک‌اند، همراه با محدودیت نرخ و مدیریت امن نشست.
2. نگهداری امن اطلاعات مشتری، داده سفارش، قیمت و موجودی در سرور.
3. پرداخت از طریق درگاه معتبر با Verify سمت سرور، کنترل تکرار درخواست و ثبت وضعیت تراکنش.
4. حذف رمزها و OTPهای نمایشی از مسیر ورود واقعی مدیر.
5. تست‌های خودکار، تست مرورگر، ارزیابی امنیتی و استقرار آزمایشی.
6. انتشار مستندات حریم خصوصی، شرایط استفاده و مجوز دارایی‌های بصری/صوتی.

## Release و نسخه‌بندی

- در وضعیت فعلی **هیچ GitHub Release و هیچ Version Tag** وجود ندارد.
- عدد `0.0.0` در `package.json` یک مقدار اولیه توسعه است، **نه** نشانه وجود Release رسمی.
- پیشنهاد: پس از تکمیل حداقل تست‌ها و رفع هشدارهای امنیتی، ابتدا یک **Pre-release** با محدوده امکانات و محدودیت‌های روشن منتشر شود.
- تا پیش از آن، از ارائه ZIP یا نسخه دارای پرداخت/ورود نمایشی به‌عنوان محصول آماده استفاده عمومی خودداری کنید.

## مجوز

فایل `LICENSE` مستقلی در ریشه مخزن مشاهده نشد. عمومی‌بودن سورس به معنای اعطای اجازه بازنشر یا استفاده تجاری نیست. حقوق تصاویر، فونت‌ها، موسیقی و دیگر دارایی‌های ثالث نیز باید جداگانه بررسی شود.
