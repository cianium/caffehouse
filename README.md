# BODRIN Specialty Coffee — Interactive Storefront Prototype

> **Status: UI/demo only. NOT suitable for accepting live payments, credentials or customer orders.**

یک نمونه وب‌اپلیکیشن واکنش‌گرا برای کافه و برشته‌کاری بودرین با طراحی تعاملی، نمایش محصولات، سبد خرید، حساب وفاداری آزمایشی و صحنه سه‌بعدی فنجان.

## فناوری

React · TypeScript · Vite · Tailwind CSS · Three.js · GSAP

## قابلیت‌های موجود در سورس

- ویترین و نمایش محصولات و اطلاعات قهوه
- صحنه سه‌بعدی فنجان و تعاملات ظاهری
- سبد خرید و فرایند نمایشی تسویه
- بخش مدیریت **آزمایشی** و رابط ورود
- نمایش امتیاز وفاداری با داده‌های سمت مرورگر

## هشدار جدی امنیتی

**ورود ادمین در این نسخه احراز هویت واقعی نیست.** بررسی سورس `src/context/AdminAuthContext.tsx` نشان می‌دهد رمز ورودی فقط از نظر طول کنترل می‌شود، OTP در مرورگر تولید شده و نشست در `localStorage` ذخیره می‌شود. داده‌ها و دسترسی‌های حساس را به این مکانیسم نسپارید.

صفحه پرداخت نیز **شبیه‌سازی رابط** است و به معنی اتصال واقعی و امن به درگاه بانکی نیست. اطلاعات کارت، رمز بانکی یا داده واقعی مشتری را در این دمو وارد نکنید. حساب‌های نمایشی و مقادیر ثابت ورود را باید پیش از انتشار عملیاتی حذف کرد.

## اجرای محلی

```bash
npm install
npm run dev
npm run lint
npm run build
```

سرور Vite در پیکربندی فعلی روی پورت `3000` اجرا می‌شود. پیش از استقرار عمومی، محیط و بسته‌ها را مستقلاً بررسی کنید.

## مسیر تبدیل به محصول واقعی

1. پیاده‌سازی احراز هویت و مجوزدهی در سرور با نشست امن.
2. انتقال سفارش، موجودی و قیمت‌گذاری نهایی به backend و پایگاه داده.
3. اتصال پرداخت واقعی فقط با hosted checkout و verify سروری.
4. انتقال اطلاعات شخصی از ذخیره‌سازی نامطمئن مرورگر به ذخیره امن و محدود.
5. افزودن CI، تست خودکار، کنترل دسترسی و آزمایش staging.
6. مستندسازی قابلیت‌های واقعی و حذف متون اغراق‌آمیز یا گمراه‌کننده درباره امنیت.

## وضعیت حقوقی

مجوز متن‌باز در ریشه مشخص نشده است. تصاویر، فونت‌ها، موسیقی و سایر دارایی‌های شخص ثالث باید پیش از بازنشر بررسی شوند.
