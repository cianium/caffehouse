# کافه و برشته‌کاری تخصصی بودرین (BODRIN Specialty Coffee)

پروژه وب‌اپلیکیشن فوق پیشرفته و سینمایی برای برشته‌کاری و کافه تخصصی **بودرین (BODRIN)** توسعه یافته با React، TypeScript، Three.js و Tailwind CSS.

---

## 🌟 ویژگی‌های برجسته پروژه

1. **ویترین و منوی مدرن و گرید افقی محصولات**:
   - دسته‌بندی کامل دانه‌های تک‌خاستگاه، نوشیدنی‌های بار گرم و سرد، اسپرسو بار و ابزارهای دم‌آوری.
   - کارت‌های لوکس با نمایش خاستگاه، پروفایل طعمی، نوع فرآوری، ارتفاع کشت و نشان‌های اختصاصی.

2. **شبیه‌سازی ۳ بعدی فنجان بیرون‌بر (Three.js)**:
   - نمایش مدل سه‌بعدی فنجان کاغذی بیرون‌بر با درپوش و کمربند مقوایی (Sleeve).
   - امکان تایپ همزمان و درج نام دلخواه مشتری روی کمربند فنجان با پیش‌نمایش زنده در محیط سه‌بعدی.

3. **باشگاه مشتریان و وفاداری (BODRIN Rewards)**:
   - محاسبه دقیق و ذخیره‌سازی سابقه خرید در `LocalStorage`.
   - نشانگر دایره‌ای متحرک پیشرفت (`SVG Radial Progress`) به سوی دریافت نوشیدنی رایگان.

4. **فرآیند تسویه حساب مرحله‌ای (Checkout Modal)**:
   - مرور اقلام و ریز محاسبات قیمت، تخفیف، هزینه بسته‌بندی لوکس و ارسال.
   - ورود مشخصات گیرنده، شهر، آدرس و کد پستی با ذخیره‌سازی خودکار.
   - فاکتور نهایی و صدور رسید خرید.

5. **درگاه پرداخت بانکی ایرانی (شاپرک و زرین‌پال)**:
   - شبیه‌سازی دقیق صفحه پرداخت شاپرک به همراه درگاه‌های معتبر بانکی (سامان، ملت، سداد و زرین‌پال).
   - تشخیص هوشمند کارت‌های ۱۶ رقمی بانک‌های ایرانی (ملی، ملت، سامان، پاسارگاد، تجارت، صادرات، شهر، سپه، آینده و ...).
   - دریافت رمز دوم پویا با ارسال پیامک فرضی، تایمر معکوس ۱۲۰ ثانیه‌ای و کپچای امنیتی.

6. **پنل مدیریت اختصاصی و تفکیک‌شده (Admin Dashboard & Login)**:
   - تفکیک کامل از فضای کاربری مشتریان (حذف دکمه‌های ادمین از دید عموم).
   - صفحه ورود اختصاصی در مسیر `/admin/login` با اعتبارسنجی دو مرحله‌ای (رمز عبور + کد اعتبارسنجی ایمیل OTP).
   - پنل مستقل در مسیر `/admin` با امکان ویرایش مشخصات سایت، شعار، شماره تماس، آدرس‌ها، شبکه‌های اجتماعی و افزودن/ویرایش قیمت و محصولات.

7. **آمبیانس صوتی کافه**:
   - شبیه‌سازی صدای محیطی قهوه‌خانه و کلیک‌های ملایم با Web Audio API بدون نیاز به فایل حجیم خارجی.

## 🚀 راهنمای نصب و راه‌اندازی محلی

برای اجرای پروژه روی سیستم خود:

```bash
# ۱. نصب وابستگی‌ها
npm install

# ۲. اجرای سرور توسعه محلی
npm run dev
```

سپس در مرورگر خود آدرس زیر را باز کنید:
```
http://localhost:3000
```

برای ساخت نسخه نهایی و بهینه‌شده برای پروداکشن:
```bash
npm run build
```

## 🔑 مشخصات ورود به پنل مدیریت

- **آدرس ورود:**
  - از طریق فوتر سایت: کلیک روی پیوند محرمانه **«پرتال پرسنلی»**
  - یا مستقیماً از طریق روت: `http://localhost:3000/#admin` یا کلیک روی منوی ادمین
- **ایمیل پیش‌فرض:** `admin@bodrin.coffee`
- **رمز عبور پیش‌فرض:** `admin123456`
- **کد تایید ایمیل (OTP):** در صفحه لاگین به صورت خودکار برای تست و کپی در دسترس است (مثال: `849201`).

## 📂 ساختار فایل‌های پروژه

- `src/components/3d/CoffeeScene.tsx`: رندرر Three.js و متریال‌های سه‌بعدی فنجان
- `src/components/3d/ProceduralTextures.ts`: بافت‌ساز و درج متن کمربند فنجان
- `src/components/BodrinRewards.tsx`: ماژول باشگاه وفاداری و پروگرس‌بار دایره‌ای
- `src/components/CheckoutModal.tsx`: فرآیند تسویه حساب چند مرحله‌ای
- `src/components/IranianPaymentGateway.tsx`: شبیه‌ساز کامل درگاه شاپرک
- `src/pages/AdminLoginPage.tsx`: صفحه اختصاصی لاگین ادمین با تایید ایمیلی
- `src/pages/AdminDashboardPage.tsx`: پنل مدیریت مستقل و پیشرفته
- `src/context/`: مدیریت استیت سراسری سبد خرید، تاریخچه، امنیت و تنظیمات سایت
- `src/utils/router.ts`: موتور روتینگ بدون وابستگی به کتابخانه‌های سنگین خارجی
